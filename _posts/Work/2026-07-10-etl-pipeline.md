※ 국방 분야 과제 특성상 사업명·발주기관·데이터 상세내용 비공개 (보안 규정 준수)

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 기간 | 2024.11 ~ 2026.12 (약 25개월, 진행 중) |
| 분야 | 국방 / 시계열 센서 데이터 정제 · 학습 데이터셋 구축 · 항적 분류 모델 개발 |
| 목표 | 실운용 환경에서 수집되는 다변량 시계열 궤적 데이터를 기반으로 이동체 유형 분류 모델 구축 |
| 역할 | 데이터 파이프라인 전 구간(수집·정제·가공·학습·검증) 설계 및 구현 |
| 기여 범위 | 데이터 처리 로직 및 모델 개발 담당 / 사업 산출물 작성·관리 |
| 개발환경 | 폐쇄망 운용 |
| 데이터 규모 | 원시 데이터 [300TB], 학습 데이터 [10만] 건 |

※ 보안상 언론 공개 자료 발췌 (실제 사업과 무관)

## 기술 스택

| 파이프라인 단계 | 기술 |
|---|---|
| 수집 · 정제 | Python · pandas · NumPy · multiprocessing |
| 가공 | Tkinter (라벨링 GUI) |
| 모델 학습 | scikit-learn · XGBoost · LightGBM · PyTorch · DTW |
| 검증 | scikit-learn (`GroupKFold` · `Pipeline` · metrics) |

## 요구사항

- 품질 증빙 : 대용량 라벨 데이터 납품 전, 형식·값·무결성을 검증하는 객관적 품질검증 체계 구축
- 파이프라인 : 데이터 처리부터 라벨링까지 수행하고, 운용 환경 추가에도 재사용 가능한 구조 구성
- 모델 성능 : 실전 항적 분류에 활용 가능한 수준의 분류 정확도 달성

## 문제 정의

- 대규모 데이터 운영 효율 : 운용 환경 추가 시 데이터 처리부터 라벨링까지 장시간이 소요되어 효율성 저하
- 데이터 품질 검증 : 전수 검수가 불가능한 규모이고, 검수자에 따라 판정 기준이 달라져 객관성·일관성 확보가 어려움
- 학습모델 성능 : 실전 환경의 극단적 클래스 불균형으로 소수 클래스의 분류 정확도 확보가 어려움

## 담당 업무 및 범위

| 단계 | 단계 명 | 수행 내용 | 상세 |
|---|---|---|---|
| 1 | 수집 | - | - |
| 2 | 정제 | 정제 데이터 정합성 검증 로직 개발 | 형식 · 값 범위 · 결측 · 무결성 자동 점검 |
| 3 | 가공 | 라벨링 자동화 툴 개발 · 라벨 품질검증 체계 구축 | 폐쇄망 대응 데스크톱 GUI · 자동/표본/3자 3층 검증 |
| 4 | 모델 학습 | 학습 파이프라인 구축 | 14개 알고리즘 학습 후 성능 비교분석 |
| 5 | 검증 | 모델 성능 평가 로직 개발 | 평가 지표 : F1-Score · 혼동행렬 |
